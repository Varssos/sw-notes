Pip main commands
=================

Uninstall package
~~~~~~~~~~~~~~~~~
::
    
    pip3 uninstall docutils

Install package with accurate version
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
::    
    
    pip3 install --upgrade docutils==0.17.1


Check pip package version
~~~~~~~~~~~~~~~~~~~~~~~~~
::

    pip show docutils
