The most common way how to setup printer
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Install printer drivers
2. Go to ``Printers`` -> ``add``
3. Add device URI: ``socket://192.168.100.206``
